# Gym Manager

A small, installable Gym Manager PWA for one gym owner. Static HTML/CSS/JavaScript; no backend required for single-device use.

## Deploy to Vercel

1. Import `Shakir120795/gym` at https://vercel.com/new.
2. Choose the `main` branch.
3. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (or leave the default if Vercel detects static content correctly).
4. Deploy, then open the HTTPS deployment URL in Chrome.

## Install

Visit the deployed HTTPS website. In Chrome, use the Install icon in the address bar or menu. On Android, use Chrome menu → Install app / Add to Home screen. The install button in the app appears where the browser supports the install prompt.

## Data storage warning

Records are stored in the browser's localStorage on the current device/profile. They do not automatically sync between devices. Export backups from Reports regularly. Clearing browser data may delete records. This simple static app has no account/login security; anyone who can open the URL can load the app, although each browser profile has its own local data. Do not store sensitive personal information unless suitable access controls and backups are added.
